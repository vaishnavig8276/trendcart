## 📖 About The Project

**TrendCart** is a full-stack e-commerce web application designed to provide users with a seamless and interactive online shopping experience. It features dynamic product rendering, smooth categorization, and a lightweight RESTful backend to manage products efficiently. 

This project demonstrates a complete web development workflow—from a responsive frontend interface to a functional Node.js server handling data.



---

## ✨ Key Features

* 🛒 **Dynamic Product Catalog:** Products are fetched directly from the backend server.
* 🔍 **Categorization & Filtering:** Easily browse products based on updated categories.
* 📱 **Responsive UI/UX:** Fully optimized for both desktop and mobile devices.
* ⚡ **Fast & Lightweight Backend:** Built using Node.js for quick API responses and asset serving.
* 🗄️ **Local JSON Storage:** Utilizes `products.json` as a lightweight database for easy product management.

---

## 💻 Tech Stack

**Client:** HTML5, CSS3, Vanilla JavaScript (DOM Manipulation, Fetch API)  
**Server:** Node.js, Express.js (or core HTTP module)  
**Database:** Local JSON File System (`products.json`)  
**Version Control:** Git & GitHub
